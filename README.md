# To-Do List (Python)

A simple console to-do list app. My first Python project.

## Features

- Show all tasks
- Add a new task
- Delete a task
- Tasks are saved to a file, so they stay after closing the program

## How to run

1. Install Python 3
2. Download this repository
3. Run the program:

```
python to-do.py
```

## What I learned

- Functions
- Reading and writing files
- Error handling with try / except
- Working with Git and GitHub
